## Screenshot 1 — Arsenal Dashboard

**Filename:** `01-arsenal-dashboard.png`

**How to capture:**

1. Open Arsenal tab
2. Ensure all 5 module cards are visible
3. At least one `ready` and one `partial` badge visible
4. H4CK_ROOT footer line visible
5. Tab nav (Arsenal | Schrödinger) in top-right

## Tips

- Resolution: 1920×1080 or 1440×900
- Dark mode is default — matches lab aesthetic
- Crop browser chrome if Devpost allows; keep URL bar for authenticity optional
- PNG format, under 5 MB each
